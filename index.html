🎯 Coordinate Grabber

Draw rectangles on images and copy their coordinates

📁 Drag & Drop an Image Here
or click to select a file
Draw rectangles to see their coordinates

How to use:

  • Drag and drop an image or click the drop zone to select a file
  • Click and drag on the image to draw a rectangle
  • You can draw multiple rectangles - each will be saved
  • Release to see the coordinates (x, y, width, height) in the list
  • Click "Copy All Coordinates" to copy all rectangles' coordinates to your clipboard
  • Click the delete button (🗑️) next to any rectangle to remove it
  • Use "Clear All" to remove all rectangles
  • Use "Reset Image" to start over with a new image
